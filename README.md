TITAN ARM – Six-Servo Robotic Arm 🤖

Project Overview

TITAN ARM is a medium-sized robotic arm designed with six servo motors. It will support both manual joystick control and wireless control through a computer dashboard.

The project aims to combine mechanical engineering, electronics, programming and robotics.

Main Features

* Six-axis robotic arm movement
* Manual joystick control
* Wireless computer dashboard
* Gripper control
* Position recording and replay
* Emergency stop functionality
* LED status indicators

Servo Configuration

Servo	Motor	Function
1	MG996R	Base rotation
2	DS3218	Shoulder movement
3	DS3218	Elbow movement
4	MG996R	Wrist tilt
5	MG996R	Wrist rotation
6	MG90S	Gripper

Final servo mounting compatibility and mechanical dimensions will be verified during assembly.

Electronics

* ESP32 DevKit
* PCA9685 16-channel servo driver
* 3 × MG996R servo motors
* 2 × DS3218 servo motors
* 1 × MG90S servo motor
* 2 × Dual-axis joystick modules
* Regulated servo power supply
* LEDs and status display

Mechanical Design

The robotic arm will use a metal 6DOF bracket kit as its main structure.

The design will include:

* Rotating base
* Shoulder and elbow joints
* Wrist tilt and rotation
* Mechanical gripper
* Servo mounting arrangements

Control System

TITAN ARM will have two control methods:

1. Manual Mode: Physical joysticks control the robotic arm.
2. Wireless Mode: A computer dashboard controls the arm through wireless communication.
