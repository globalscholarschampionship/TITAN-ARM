# TITAN-ARM
A medium-sized robotic arm with joystick and wireless control.

TITAN ARM is a medium-sized robotic arm designed to pick up and move lightweight objects.

Main features

* Joystick-controlled movement
* Wireless computer control
* Servo-powered joints
* Robotic gripper
* Position recording and replay

Hardware

* ESP32 development board
* PCA9685 servo driver
* DS3218, MG996R and MG90S servos
* Metal robotic arm frame

Project status

Currently in the design and development stage.
